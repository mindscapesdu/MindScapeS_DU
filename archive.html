Concluded • Session 1 Held on Friday, October 30, 2026 • 6:30 PM IST

Minimal object representations in the infant mind

Speaker: Prof. Melissa M. Kibbe (Boston University, USA)
Commentator: Prof. Sami Yousif (The Ohio State University, USA)

An inaugural colloquium examining the cognitive architecture of object representation, feature binding, and conceptual development in infants and young children. The discussion explored how working memory tracks discrete object files and how computational constraints inform models of mental representation.
